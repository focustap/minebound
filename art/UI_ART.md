# Interface artwork provenance

Generated with the built-in imagegen tool for this expansion; the supplied enemy sheets remain intact in `art/source/world1`. The original UI backgrounds are saved under `src/main/resources/assets/minebound/textures/gui/` and use nearest-neighbor texture metadata. Runtime text, buttons, map markers, skill nodes and connections are rendered separately.

Use case: stylized-concept. Asset type: original PNG pixel-art background for Minebound, a Minecraft menu RPG world-selection map. Create a landscape enchanted forest board-game map, aspect ratio 3:2, crisp limited-palette SNES-inspired original pixel art. Deep ink-purple border woods, winding golden footpath from lower left via a mossy pond and ruined stone watchtower to a great crooked root-castle at upper right. Five spacious clearings along the route for interactive stage markers; no baked-in markers or buttons. Tiny teal mushrooms, amethyst crystals, warm fireflies and layered fern-green foliage. Deliberate large pixels, nearest-neighbor appearance, no antialiasing, no photographic textures. Color palette ink #171426, plum #2B2444, parchment #F3E9D2, fern #6EA484, gold #E8B86C, lavender #CDBDE9. No letters, words, numerals, watermarks, existing franchise characters, Minecraft blocks, interface text or logos. Original fantasy environment only, readable composition and lower contrast central route.
